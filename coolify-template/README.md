# Coolify one-click submission

Drafts for adding **FluxWP WordPress** to Coolify's service list. Nothing here is used by the stacks in this repository.

| File | Goes to |
|---|---|
| `fluxwp-wordpress.yaml` (generated by `tools/build.py`) | `coollabsio/coolify` › `templates/compose/fluxwp-wordpress.yaml` |
| `fluxwp-wordpress.svg` | `coollabsio/coolify` › `svgs/fluxwp-wordpress.svg` and `coollabsio/coolify-docs` › `public/images/services/` |
| `fluxwp-wordpress.mdx` | `coollabsio/coolify-docs` › `content/docs/services/fluxwp-wordpress.mdx` |

Requirements from https://coolify.io/docs/get-started/contribute/service (checked 2026-11-05):

- External contributions are currently paused.
- The service repository needs at least 1,000 GitHub stars.
- The template PR targets the current `release/v4.x` branch and links the docs PR. Both are tested with a fresh **Docker Compose Empty** resource.
