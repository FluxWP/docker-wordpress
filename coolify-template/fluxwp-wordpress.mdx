## What is FluxWP WordPress?

FluxWP WordPress is WordPress with production defaults, packaged as one stack:

- WordPress (Apache, PHP 8.4) with tuned PHP and OPcache, 128 MB uploads and hardening
- MariaDB 11.8 LTS, tuned for small servers
- Redis object cache, enabled automatically
- A worker container that installs WordPress on the first deploy (no public install screen) and runs WP-Cron every minute
- Optional install of FluxWP Panel, the FluxWP plugin installer and updater

The images are rebuilt every day, so PHP security fixes arrive on the next deploy.

## Configuration

All variables are optional.

| Variable | Default | Description |
|---|---|---|
| `WP_ADMIN_EMAIL` | `admin@<domain>` | Admin e-mail. WordPress installs itself on the first deploy; log in with `SERVICE_USER_WPADMIN` / `SERVICE_PASSWORD_WPADMIN`. |
| `WP_AUTO_INSTALL` | `true` | `false` shows the browser install screen instead |
| `WP_TITLE` | `WordPress` | Site title for the automatic install |
| `WP_LOCALE` | `en_US` | Site language, e.g. `de_DE`, `tr_TR` |
| `WP_TIMEZONE` | `UTC` | Site timezone |
| `FLUXWP_SETUP` | `false` | `true` installs FluxWP Panel |
| `PHP_UPLOAD_MAX_FILESIZE` / `PHP_POST_MAX_SIZE` | `128M` | Upload limits |
| `PHP_MEMORY_LIMIT` | `256M` | PHP and WordPress memory limit |
| `REDIS_MAXMEMORY` | `128mb` | Redis cache size |
